# TaskFlow

Uma API para criar e gerenciar tarefas usando Python e FastAPI.

## O que já tem

- Criar tarefas
- Listar tarefas
- Buscar tarefa por ID
- Atualizar tarefa
- Deletar tarefa

## Tecnologias

- Python
- FastAPI
- Pydantic

## Rodando

Clone o projeto:

```bash
git clone https://github.com/nubackK/taskflow.git
cd taskflow
```

Instale as dependências:

```bash
pip install fastapi uvicorn
```

Rode:

```bash
fastapi dev main.py
```

API:

`http://127.0.0.1:8000`

Swagger:

`http://127.0.0.1:8000/docs`
